===================huggingface下载模型===================
# 命令行中下载
pip install huggingface_hub[hf_cli]
hf download HuggingFaceTB/Countdown-Task-GOLD --repo-type dataset --local-dir your-path
这里注意：下载下来的模型是单独的文件，请在your-path中用个文件夹框起来

# python中加载数据
train_dataset = Dataset.from_parquet(
    "your-path/.parquet"
)


===================modelscope下载模型===================
pip install modelscope

modelscope download --model LLM-Research/Llama-3.2-1B-Instruct --local_dir ./dir
